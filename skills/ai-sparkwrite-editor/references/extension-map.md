# Extension Map

Load before adding imports, toolbar buttons, bubble menus or extension arrays. Snapshot: **1.1.0 / Tiptap ^3.29.2**. Installed declarations (`lib/index.d.ts`, `lib/core.d.ts`, `lib/vue.d.ts`) override this map.

## Entry points

| Entry                                                              | Contents                                                                                                                                                                                                                                      | React?                                   |
| ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| `ai-sparkwrite-editor`                                             | Everything for React: provider, toolbar primitives, kit, every extension with its React node view and `RichText*` control, bubble menus, AI layer, `localeActions`/`useLocale`, `themeActions`/`useTheme`, `registerIcons`, `getShortcutKeys` | yes                                      |
| `ai-sparkwrite-editor/vue`                                         | Same names for Vue 3: provider, composables, primitives, kit, controls, node views, bubbles, AI; re-exports the framework-free extensions so one import suffices                                                                              | no (vue, @tiptap/vue-3, lucide-vue-next) |
| `ai-sparkwrite-editor/core`                                        | Framework-free extensions (blocks without node views), AI engine (`AI` headless, `writeWithAI`, `AIAutocomplete`, `generateAIText`, Markdown helpers), `Recorder`, image bookkeeping, `localeActions`                                         | no                                       |
| `ai-sparkwrite-editor/<feature>`                                   | One feature (extension + React control), e.g. `/bold`, `/image`, `/ai`, `/notice`, `/iframe`                                                                                                                                                  | yes                                      |
| `ai-sparkwrite-editor/bubble/<name>`                               | One bubble menu: `text`, `link`, `media`, `table`, `iframe`, `notice`, `callout`, `katex`, `mermaid`, `drawer`, `excalidraw`, `twitter`, `drag-handle`, `ai`; `/bubble` is the barrel                                                         | yes                                      |
| `ai-sparkwrite-editor/locale`, `/locales/<file>`, `/locale-bundle` | English + actions; one dictionary; every dictionary as a side effect                                                                                                                                                                          | no                                       |
| `ai-sparkwrite-editor/theme`                                       | `themeActions`, `useTheme`, `THEME`, `CODE_THEME`                                                                                                                                                                                             | React hook                               |
| `ai-sparkwrite-editor/style.css`                                   | The stylesheet (controls + document styles). Always import once                                                                                                                                                                               | —                                        |

The main entry is fully tree-shakable (each feature is its own chunk), so `import { Bold } from 'ai-sparkwrite-editor'` costs the same as `/bold`.

## Bubble menus

React: `RichTextBubbleText` (Improve menu when AI is registered, block type, marks, link, colour, highlight, alignment), `RichTextBubbleLink`, `RichTextBubbleImage`, `RichTextBubbleVideo`, `RichTextBubbleImageGif`, `RichTextBubbleTable`, `RichTextBubbleIframe`, `RichTextBubbleNotice`, `RichTextBubbleCallout`, `RichTextBubbleKatex`, `RichTextBubbleMermaid`, `RichTextBubbleExcalidraw`, `RichTextBubbleDrawer`, `RichTextBubbleTwitter`, `RichTextBubbleMenuDragHandle`, `RichTextAIImprove`.

Vue: `RichTextBubbleText`, `RichTextBubbleTable`, `RichTextBubbleLink`, `RichTextBubbleImage`, `RichTextBubbleNotice`.

`RichTextKitMenus` mounts all of the above that apply (React) / the Vue five plus the composer.

## Companion nodes and overlaps

- `BulletList`/`OrderedList` need `ListItem`; `Color`, `Highlight`, `FontFamily`, `FontSize`, `LineHeight` need `TextStyle` (`@tiptap/extension-text-style`). The kit registers both.
- Register all three column extensions together and widen `Document` (`Document.extend({ content: '(block|columns)+' })`).
- `Table` brings row/header/cell/cell-background, `TaskList` brings `TaskItem`, `Details` its summary/content, `TableOfContents` its node, `Image` both `image` and `imageBlock`: do not register them twice.
- `Divider` replaces `HorizontalRule`; register one of them.
- StarterKit: disable the features you take from this package.

## React-only (not in `/vue` or the Vue kit)

Excalidraw, Drawer, Twitter, Emoji, Mention, ShortMessage, FormatPainter, the slash menu (`SlashCommand`/`SlashCommandList`), MoreMark and Code View controls, the search-and-replace panel. Their framework-free parts exist where applicable; the UI does not.
