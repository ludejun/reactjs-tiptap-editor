# Features

Every feature is one import: the extension and its control come from the same subpath. Register the extension in `useEditor`, place the control inside `RichTextProvider`. Options are passed with `.configure({ ... })`; every extension also accepts the shared `toolbar`, `divider`, `spacer` and `shortcutKeys` options.

## Bubble menus

Imported individually from `sparkwrite/bubble/<name>`: `text`, `table`, `media` (image), `video`, `link`, `callout`, `drawer`, `excalidraw`, `iframe`, `katex`, `mermaid`, `drag-handle`. See [Bubble menus](/guide/bubble-menu).

## Languages

`sparkwrite/locales/<code>` for `en`, `zh_CN`, `hi`, `es`, `fr`, `bn`, `pt_BR`, `ru`, `id`, `de`, `ja`, `tr`, `vi`, `ko`, `it`, `hu_HU`, `fi`. See [Internationalization](/guide/internationalization).

## Theme

`sparkwrite/theme` exports `themeActions` (`setTheme`, `setBorderRadius`, accent colour) and `CODE_THEME`. Styles come from `sparkwrite/style.css`; the root element carries the `sparkwrite` class.
